# TMPPP – Mobile Cross-Platform Application (.NET MAUI)

## Descriere
Aplicație mobilă cross-platform (Android & iOS) dezvoltată în .NET MAUI (C#),
destinată gestionării notițelor zilnice și monitorizării stării emoționale (Mood Tracker).

## Tehnologii
- .NET MAUI
- C#
- MVVM Architecture
- SQLite (local storage)

## Pattern-uri de proiectare utilizate
- MVVM
- Command
- Observer
- Repository
- Unit of Work
- Factory Method
- Builder
- Strategy
- Facade

## Scop
Proiect realizat în cadrul disciplinei TMPPP (Tehnici și Mecanisme de Proiectare a Produsului Program).
